This project is a browser incremental game.
I built it in 20 hours for Terra online program (more info at https://terra.hackclub.com/). Since its a website i used HTML, CSS and JavaScript. I did not use any frameworks and. I used one library animejs for dragging elements and animation.
To run the game open the website. Press "Make box" then place the box on the brown square. After press "Make loot" and drag the loot to the placed box. Then press "Pack box" and drop it into the "drop off area".
You should get your cash that you can see at the top of your screen. Once you obtain some cash you can scroll down to buy upgrades that will help you earn more money to prestige.
